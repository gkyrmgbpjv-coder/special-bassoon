# Awesome DESIGN.md

Source : VoltAgent/awesome-design-md (licence MIT, voir `LICENSE`).

Chaque dossier `design-md/<marque>/` contient un `DESIGN.md` (tokens, règles, patterns) et un `README.md`.

## Utilisation
1. Lister les références : `ls .claude/skills/awesome-design-md/design-md`.
2. Lire uniquement le ou les `DESIGN.md` pertinents pour la demande (ne pas tout charger).
3. Ne jamais copier l'identité d'une marque (logo, nom, couleur signature) dans un autre projet : en extraire la méthode (hiérarchie, échelle typographique, rythme, densité, états).

## Pour ce dépôt (Abondance)
La direction artistique est fixée dans `CLAUDE.md` (nuit de bistrot, ambre réservé à « Réserver », Big Shoulders / Instrument Sans / Courier Prime). Les DESIGN.md servent de références de rigueur, pas de palette.
Références utiles : `starbucks` (restauration), `wired` et `theverge` (éditorial), `apple` (mise en scène produit).
