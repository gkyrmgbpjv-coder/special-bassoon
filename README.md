# Abondance — site du restaurant

Site vitrine du restaurant Abondance, 81 bis avenue de Bayonne, 31240 L'Union.

Site statique, sans étape de build : il suffit d'ouvrir `index.html` dans un navigateur ou de déployer le dossier tel quel (Netlify, Vercel, GitHub Pages).

Voir `CLAUDE.md` pour le contexte, les informations à compléter et la direction artistique.
